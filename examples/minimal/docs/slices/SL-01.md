# SL-01: Walking skeleton, a vacuum shot end to end with provenance
Order: 1 · Risk: high

## Scope
From a `ScenarioConfig` to a `Trajectory` with provenance, through the integrator
and the atmosphere contract (stubbed), with drag disabled. Cuts every layer thinly.

## Acceptance criteria
1. `simulate` of a 100 m/s shot at 45° with drag off returns a range within 0.5 %
   of v² sin 2θ / g when dt ≤ 0.01 s.
2. The returned `Trajectory` carries engine version, config hash, seed, and commit.
3. Running the same config twice returns equal `Trajectory` objects, compared exactly.
4. A config dictionary with an unknown key is rejected, not silently ignored.
